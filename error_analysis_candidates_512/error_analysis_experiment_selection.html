Experiment Selection for Error Analysis

This document summarizes the 18 configurations selected for the qualitative error analysis: six configurations per dataset, with three configurations for Llama 3.1 8B and three for Mixtral 8x7B.

For each model and dataset, the selection includes a high-performing configuration, a low-performing or diagnostically relevant configuration, and an additional comparative configuration chosen to examine prompt design or example selection effects.

Each linked report contains the 15 examples with the lowest SARI scores for that configuration.
