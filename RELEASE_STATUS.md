# Artifact scope and versioning

This expanded artifact set covers the 162-configuration main study, separate ablation and repetition-penalty diagnostic. This artifact set is published on the main branch. The existing v1.0.3 tag refers to the earlier artifact set and is not relabeled or replaced. Cite the commit used until a new versioned release is assigned.

The release_verification.json file records checks performed during local assembly, not a claim that a release tag was created. Dataset attribution and redistribution notes are preserved in data/README.md and apply also to source/reference text reproduced in predictions and reports. Final article PDFs and author-response documents are not included.
